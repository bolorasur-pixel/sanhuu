# arga. Хувийн санхүү — утсанд суулгадаг вэб апп

Энэ хавтсанд байгаа 8 файлыг ямар ч статик хостинг (GitHub Pages, Cloudflare Pages, Netlify) дээр байршуулахад утсан дээр апп шиг суулгадаг, интернэтгүй ажилладаг хувилбар болно. Сервер, мэдээллийн сан, сарын төлбөр шаардлагагүй.

| Файл | Үүрэг |
|---|---|
| `index.html` | Апп өөрөө (бүх загвар, програм, фонт дотор нь) |
| `manifest.webmanifest` | Утсанд «апп» гэж танигдах нэр, өнгө, дүрс |
| `sw.js` | Интернэтгүй үед ажиллуулах кэш (service worker) |
| `icon-*.png`, `apple-touch-icon.png` | Нүүр дэлгэцийн дүрс |
| `.nojekyll` | GitHub Pages файлыг өөрчлөхгүй байх тохиргоо |

## GitHub Pages дээр байршуулах (≈10 минут)

1. https://github.com/signup хаягаар үнэгүй бүртгэл үүсгэнэ. Хэрэглэгчийн нэр хаяг тань болно: `НЭР.github.io`.
2. Баруун дээд буланд **+ → New repository** дарна.
   - Repository name: жишээ нь `sanhuu`
   - **Public** сонгоно (үнэгүй багцад Pages зөвхөн Public дээр ажилладаг)
   - **Create repository** дарна.
3. Нээгдсэн хуудсан дээр **uploading an existing file** холбоосыг дарж, энэ хавтасны **бүх файлыг** чирж оруулна. Доод хэсэгт **Commit changes** дарна.
4. **Settings → Pages** руу орно. **Source: Deploy from a branch**, **Branch: main / (root)** сонгоод **Save** дарна.
5. 1–3 минутын дараа дээд талд `https://НЭР.github.io/sanhuu/` хаяг гарч ирнэ. Энэ бол таны апп-ын линк.

## Утсанд суулгах (хэрэглэгчдэд өгөх заавар)

- **iPhone:** линкийг **Safari**-аар нээнэ → доод хэсгийн «Хуваалцах» (□↑) → **Нүүр дэлгэцэд нэмэх**. Энэ алхам заавал хэрэгтэй: нүүр дэлгэцэд нэмээгүй бол Safari 7 хоног ороогүй сайтын мэдээллийг устгаж болзошгүй.
- **Android:** линкийг **Chrome**-оор нээнэ → апп доторх **«Суулгах»** товч эсвэл цэснээс **Апп суулгах**.
- **Компьютер:** Chrome/Edge-ийн хаягийн мөрний баруун талын суулгах дүрсийг дарна.

## Шинэ хувилбар гаргах

1. Шинэ `index.html`-ийг дахин upload хийнэ.
2. `sw.js` доторх `VERSION`-ийг өөрчилнө (жишээ `arga-v5.0.1`).
3. Хэрэглэгчийн апп дараагийн нээлтэд автоматаар шинэчлэгдэнэ. Мэдээлэл нь хэвээр үлдэнэ.

**Хаягаа бүү соль.** Мэдээлэл тухайн хаягт холбогдож хадгалагддаг тул хаяг (хэрэглэгчийн нэр, repository нэр, домайн) солигдвол хэрэглэгчид өгөгдлөө «Өгөгдөл → JSON хуулбар»-аар шилжүүлэх шаардлагатай болно.

## Анхаарах зүйлс

- **Арилжааны хэрэглээ:** GitHub-ийн дүрмээр Pages-ийг онлайн бизнес, арилжааны програм үйлчилгээ байршуулахад ашиглахгүй байхыг заасан. Төлбөртэй борлуулах бол Cloudflare Pages эсвэл Netlify-ийн нөхцөлийг шалгаж, тэнд байршуулахыг зөвлөж байна. Файлууд нь ижил, зөвхөн 3-р алхам өөр (сайт руу хавтсаа чирж оруулна).
- **Код нээлттэй:** Public repository-ийн кодыг хэн ч харж, хуулж чадна.
- **Хэрэглэгчийн мэдээлэл:** хэзээ ч таны сервер рүү очихгүй, зөвхөн хэрэглэгчийн төхөөрөмжид (PIN тохируулсан бол шифрлэгдсэн байдлаар) хадгалагдана.
